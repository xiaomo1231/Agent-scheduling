# 中枢：产品设计要点

这里是界面原型（`demo/index.html`）阶段定下的产品设计，供后续版本对照。已经实现到哪一步见 [roadmap.md](roadmap.md)。

- **项目页像 Claude Code 一样分栏**：默认左边是协调者（项目对话，它开讨论串、发卡片），右边是讨论串（列表 ↔ 详情，面包屑“讨论串 › 名称”）。布局像 iOS 桌面：项目页是一块 12 × 8 的画布，点“调整布局”或长按标题栏进入编辑，模块轻微晃动，拖动挪位置、拖右下角改大小（吸附网格），别的模块自动让位，放不下时和被压住的模块对调；从模块库添加（小 / 中 / 大），点 − 移除；也能套用现成布局。团队、可视化、总线、评审、记忆收进 ⋯ 菜单，项目设置是单独的弹窗（通用 / 团队与模型 / 记忆 / 环境 / 使用情况 / 权限）。
- **讨论串解决**：照 Claude 的做法，侧栏只显示活跃讨论串，已解决的收进列表底部。协调者在计划全部完成、没有等你批准或回答、没有待合并 PR 时自动解决并留言说明；你也能在讨论串头部点 ✓ 手动解决；往已解决的讨论串发消息会自动重新打开。项目设置里可改成只由你手动解决。
- **设置照 OpenClaw 分组**：左侧设置导航分个人（外观主题、通知）、连接、agent 与工具（含 Skills、MCP 与搜索）、隐私与安全、系统（含网关、日志、更新、实验室）五组，带搜索、“问中枢”一句话改设置、Esc 返回。顶栏“运行中”打开系统繁忙程度（各通道活跃 / 排队 / 阻塞、各订阅剩余额度、网关资源）。
- **安全默认开**：命令策略五档 + 精确到参数的白名单（审批卡“以后都允许这类”自动加入）；内联代码一律审批；无人审批默认拒绝；批准绑定命令指纹，改动即作废；子 agent、定时任务、第三方 skill 脚本默认进沙箱；联网和执行命令不同时给一个 agent；外部内容当不可信数据。“安全体检”页列出偏离默认的地方并一键修复，另有紧急停止。
- **Skill 通用模板**：以 SKILL.md 开放标准为底，加 `metadata.zhongshu` 扩展块（权限申请、依赖、通用工具名、投放目标）。导入单平台 skill 时：识别来源 → 静态扫描 → 转换 agent 在只读沙箱改写 → 另一个模型复核 → 你确认权限 → 安装（指纹锁定）并投放到各 agent 的 skills 目录；也能导出回任一平台格式。skill 只能申请权限，不能授予权限。
- **思考强度按模型分挡**：Opus / Fable 五挡，GPT-6 Astra 五挡，GPT-5 四挡，GLM / DeepSeek / Kimi 等是“快速 / 深度思考”。分组里的每个用途、团队表里的每个模型、每个讨论串、协调者和双脑的副脑都能单独调；可以打开“自动调挡”，简单的事降挡省额度。
- **双脑**：审计划（副脑先审主脑拆的计划，改完再派活）或备用（主脑额度用完、限流、报错时副脑接手），在项目设置里能看到两种模式的具体说明。
- 协调者 = 脑子 + 身体：身体（任务图、派活、审批、记忆、留痕、预算）在中枢里，以 MCP 工具提供；脑子可以是 API 模型（中枢引擎直接调用），也可以是订阅模型（如 Claude Fable、GPT-6 Astra，由官方 Claude Code / Codex CLI 无界面模式代跑，只能派活）。支持双脑（审计划或备用）和中途换脑子。
- 讨论串：项目首页是讨论串总览（等你处理、进行中、空闲、已解决），一个项目下可以有多个讨论串，每个带自己的计划清单；运行中随时追加消息，协调者判断是新增、改顺序、取消还是另开讨论串，自动改计划并给出可撤销的改动说明。
- 子 agent：协调者可临时拆出子 agent 并行干小活，可设模型、最多同时几个、单个花费上限、能做什么。
- 工作台模块化：文件、任务图、Agent 状态、GitHub、网页预览、终端、测试结果、问题与工单、依赖、数据表、来源清单、文档草稿、定时任务、用量、项目记忆等模块可增删、拖动、调宽窄；内置 8 个模板（代码开发、项目维护、Bug 修复、网页与前端、需求调研、数据收集整理、写作与内容、自动化运营），新建项目时选，可存为自己的模板。
- 模型来源两层：订阅 / Coding 与 Token Plan / API key / 本地 → 每个来源里的模型（可勾选启用）。多家模型的 Plan（OpenCode Go、火山方舟、阿里云百炼、Copilot、OpenRouter 等）里的模型单独列出，与官方 API 的同名模型分开。DeepSeek 官方没有 Coding Plan。
- 分组按用途：每组给协调、写提示词、执行、审查等用途各选一个模型，每个模型单独设备用。
- 接力流程预设：在设置里建，团队页和首页直接选，也可以让协调者帮忙搭。
- 消息渠道和连接平台：每个都有接入教程和完整设置。
- 界面布局：参考 Claude，左栏是项目、对话和任务列表，设置在左下角单独一页；项目打开后是工作台（左边文件、任务图、Agent 状态、GitHub，右边和协调者对话，顶部页签切团队、可视化、总线、评审、记忆）；普通对话和单 agent 任务不经过协调者，左边显示产出，右边对话，可一键升级为项目。
- 连接平台：GitHub、GitLab、Gitee、Linear、Jira、Sentry、Vercel、数据库（只读）、飞书、Notion、语雀、Google Drive、Figma 等，走官方 OAuth 或 MCP；每个项目单独开放，动作按权限档位，合并、删除、对外发消息默认要批准。
- 账号与模型：应用内登录（官方 CLI）或填 API key / Coding Plan / 本地模型，保存一次；按自己的习惯分组（代码、后端、网页、调研、便宜干活），每组排主用和备用，额度用完自动切换。
- 团队与模型：每个岗位选 agent 和模型来源；一个岗位可挂两个 agent（如 Claude Code + DSH），配合方式为分工、主备、并行对比、写 + 审；只有一个 agent 时协调者照常拆任务，可由该 agent 兼任或用便宜模型。新建项目时可先选协调者，再一键配置或进去细选。
- 接力：贵的模型写提示词和验收标准，便宜的模型执行，贵的模型验收，中枢自动传递，可逐步暂停。
- 调研项目：先定字段再抓取，抓取整理用便宜长上下文模型，核查换另一家模型，每条数据带来源；产出数据表、来源清单、结论报告；不开工作区和代码权限。
- 首页与问答：先建项目再进任务台；也可以直接提问。问答支持选词提问、钉住、改写并分支、多模型对比、上下文用量、转为项目、存入记忆。

- 协调者：LLM 自动拆任务 + 可保存的流程模板，协调者只派单不写文件。
- 通信总线：agent 之间所有消息都可见，可暂停、改写、拦截。
- 权限分档：限制 / 部分权限 / 完全权限，高风险事项默认人工审批。
- 选词提问：选中文字开旁支对话，结束时选择丢弃、只合并结论或全部合并。
- Agent 身份与留痕：每个 agent 有身份编号，所有消息带编号、来源和哈希链，可校验、可导出。
- 调度控制：并发、限流与重试、预算、防失控、优先级与安静时段，一键急停。
- 消息渠道：Telegram、飞书、钉钉、企业微信、Discord、Slack，可收审批、看进度、下达任务。
- 账号池：每个模型位一个主用 + 多个备用 plan/API，用完、限流、出错时自动切换并留痕。
- 群聊评审：7 个内置预设（含中立调研） + 用户自写角色提示词，每个预设含反方角色，结论由用户或可选模型的决策者拍板。
- 工作可视化：办公室 / 看板 / 依赖图 / 时间线四种视图，数据面板和轻松两种风格；每 5 分钟生成进度摘要，进程心跳持续显示，审批和报错立即提醒；支持拖动改派、时间线回放、日报周报。
- 工作区与协作：worktree 隔离、沙箱、策略约束、协作方式、一键开 PR 均可选，每项附效果和代价说明。
- 记忆：桌面页（≤4KB）+ 分层柜子 + 日档，白天投票、每日定时整理；分用户全局、项目共享、agent 私有三层。
- 账号：订阅账号只通过官方 CLI 自己的登录流程使用；Coding Plan、API key、本地模型走模型网关。
